## 📄 Descrição do entregável

* Sistema SaaS para gerenciamento escolar.
* Dashboard com visão geral das informações.
* Página para gerenciamento de escolas.
* Página para gerenciamento de professores.
* Página para gerenciamento de alunos.
* Interface responsiva e adaptada para diferentes dispositivos.
* Sistema de tema claro e escuro.
* Armazenamento dos dados utilizando LocalStorage.

---

## 💻 Sobre o projeto

O **SaaS Escolar** é um projeto desenvolvido durante o curso **"Inteligências Artificiais Generativas Aplicada à Programação - ChatGPT"**.

O projeto foi criado com o objetivo de aplicar conceitos de **HTML, CSS e JavaScript** no desenvolvimento de uma aplicação web com características de um sistema SaaS.

A aplicação simula uma plataforma de gerenciamento escolar, permitindo visualizar e administrar informações relacionadas a **escolas, professores e alunos**, além de apresentar um dashboard com os principais dados do sistema.

Durante o desenvolvimento, a **Inteligência Artificial Generativa** foi utilizada como ferramenta de apoio à programação, auxiliando no processo de desenvolvimento, resolução de problemas e implementação das funcionalidades.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Dferreiraz/Saas-Escolar.git
```

### 2. Acesse a pasta do projeto

```bash
cd Saas-Escolar
```

### 3. Execute o projeto

Como o projeto utiliza HTML, CSS e JavaScript puro, não é necessário instalar dependências com `npm`.

Você pode abrir o arquivo `index.html` diretamente no navegador.

Também é recomendado utilizar o **Live Server** através do VS Code para executar o projeto localmente.

---

### Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:

* [Git](https://git-scm.com/)
* [Visual Studio Code](https://code.visualstudio.com/)

Para executar o projeto, também é necessário possuir um navegador moderno, como Google Chrome, Microsoft Edge ou Mozilla Firefox.

## 🛠 Tecnologias

As seguintes tecnologias foram utilizadas na construção do projeto:

#### **Front-End**

* **HTML5** — Estruturação das páginas

#### **Inteligência Artificial**

* **ChatGPT** — Utilizado como ferramenta de apoio durante o desenvolvimento do projeto.
